# Super-Store-Sales-DashboardSK

Developed an interactive sales dashboard to analyze Sales, Profit, Quantity, Region, Category and Ship Mode.
Implemented slicers, KPI cards, YoY analysis and interactive visualizations.
Identified key sales and profitability trends across regions and product categories.

Interactive Power BI dashboard developed to analyze Super Store sales performance and generate actionable business insights.

🔹 Key Features
Sales, Profit & Quantity KPIs
Regional & State-wise analysis
Customer Segment & Payment Mode analysis
Category & Sub-Category performance
Ship Mode analysis
Monthly Sales & Profit YoY comparison
Interactive Region slicer
Dynamic charts and tables


🛠️ Tools Used
Power BI | Power Query | DAX | Data Modeling | Data Visualization
